# Spike 15 — Completed

One short paragraph per landed PR, newest first. PR map: [`deployment-plan.md`](deployment-plan.md).

**S15-16 — Citations render through their type's formats** ([#914](https://github.com/Jake-Robins-Studios/provenencia/pull/914)). `RenderCitations` (method 124) renders each Citation's full and short citation from its Source type's formats, as styled runs and plain text, with a group key (equal for the same rendered full citation, one per Citation when the type has no full format) and the Evidence graphs and Sources it read; at most 2,000 ids and 8 MiB per call, in 9 SELECTs at 300 Citations and 11 at 1,200. `RenderCitationPreview` (125) renders one form against one Citation, or the list form against one Source, with an optional unsaved format written with keys, and reports what a needed chain lacks and what is wrong with the text; `ListCitationBuiltins` (126) lists the built-ins from the engine's table. Boards and renders answer through one resolver (`sourcemetadata.CitationValues`) and one option rule (`AppendOptions`), and by-id batch reads of Citations, Sources, types and fields share one column list per table. Swift gains parity enums for options, diagnostic codes and built-ins in `CitationFormatVocabulary.swift`. No view calls any of it yet (S15-17, S15-21 – S15-23). Product 0.28.0.

**S15-38 — Boards carry their citation's requirements** ([#910](https://github.com/Jake-Robins-Studios/provenencia/pull/910)). Every metadata board the engine returns says, for each entry, whether the Source type's citation formats need it (outside every group), use it (inside one) or do not read it, and for a needed entry whether a later option of its chain already has a value and what those options are (`MetadataWorkspaceEntry.requirement`, on every board read and write reply). A chain is flagged on its first option; a field that heads a chain shows even when the type does not suggest it, a needed one also when dismissed, and later options only where suggested or valued. `DismissSuggestion` refuses a needed field (`sourcemetadata.invalid`, the field's id as params[0]). `GetDraftMetadataBoard` (method 123) reads the board a new Artifact or graph starts with on a Source, and `GetSourceWorkspaceResponse` carries the Source date's and the printed page's requirements. A type's three formats parse once (`Formats.Parse`, `RequirementsTx`), and `sourcemetadata.CitationValue` and `sources.CitationDate` are the one mapping from a stored value to a citation value. No view draws any of it yet (S15-39, S15-42, S15-45). Product 0.27.0.

**S15-44 — The printed page can be marked unknown or supplied** ([#905](https://github.com/Jake-Robins-Studios/provenencia/pull/905)). A Citation locator's `page` selector accepts `page_unknown` and `page_supplied`; a selector holding only `page_unknown` is valid (an image whose original prints no page). `locator.Validate` is the write check: it refuses a pair `valuemark.Validate` refuses (`valuemark.invalid`; the printed page's label is the value, the file page is not), while reads go through `parse`, which does not check the pair. `PageRef` gains `Mark`, and `citationPage` returns the whole `PageRef` with the stored mark settled by `valuemark.Settle`, so an old locator reads unmarked and a crafted pair never reaches the resolver. A depiction's region check ignores the mark. `FuzzValidate` covers the parser. No view sets or shows the mark yet (S15-45). Product 0.26.0.

**S15-53 — A metadata value never reads a mark it cannot have** ([#902](https://github.com/Jake-Robins-Studios/provenencia/pull/902)). One pure `valuemark.Settle(m, hasValue)` holds the read rule: a value that is there cannot be unknown, and one that is not there cannot be supplied, so its result always passes `Validate`. `sources.settleDate` calls it, and `sourcemetadata`'s outward reads (`ReadDraftsTx`, `ListByOwnersTx`, `ListWorkspaces`) go through `readByOwners`, which settles each row with blank text counting as none, as the write does. A crafted catalog's unknown-beside-text value now reads unmarked, and Copy Source of it succeeds. The write paths (`readOwnerTx`, `getPairTx`) still read the stored pair, so a write over a damaged row records the repair in its change. No visible change; product 0.25.1.

**S15-43 — The Source date can be marked unknown or supplied** ([#900](https://github.com/Jake-Robins-Studios/provenencia/pull/900)). A Source's date can be stored as unknown (no date row; it sorts with the undated) or supplied (a date not on the record), checked by `valuemark.Validate` in Go and by the same rules in the table (migration `000068`: `date_unknown` and `date_supplied` on `sources`). `sources.SetDate` takes the mark and writes it with the date id in one statement; a write with no mark clears the stored one, and a supplied date whose row is gone reads undated with no mark, and a date that is there never reads unknown. Every Source read fills `DateMark` through one `settleDate`, from one `sqlColumns` list and one `scanSource`. Copy Source carries the mark with the Published date tick. The `source` change holds `date_unknown` and `date_supplied` when they differ, and the delete change holds a set mark. `datevalue.Validate` refuses a phrase over `MaxPhraseBytes` (4096). The proto gains `mark` on `SetSourceDateRequest` and `date_mark` on `Source`. No view shows or sets the mark yet (S15-42). Product 0.25.0.

**S15-15 — Source types store citation formats** ([#871](https://github.com/Jake-Robins-Studios/provenencia/pull/871)). **S15-14 — The citation format engine** ([#868](https://github.com/Jake-Robins-Studios/provenencia/pull/868)). `core/citationformat` is the one engine for a Source type's citation formats, in Go with no database and no caller yet: `Parse` reads the syntax (levels named, groups, italics, chains, escapes) into a tree or into every diagnostic with its byte span; `Render` fills it through a resolver into italic and plain runs, with unknown and supplied values printed as citation style marks them, and stops at 64 KiB of text; `Requirements` and `Missing` say which fields a type's formats need or use and which needed ones have no value; `RewriteFields` moves a format's field references between keys and ids without touching any other byte. The built-in placeholders are one table. `datevalue.CitationDisplay` writes a date in citation terms ("ca. 1880", "3 March 1830", "1878–1882") on the same end formatter as `CompactDisplay`, whose output is unchanged. The pure `core/valuemark` holds the unknown and supplied pair and its `Validate` (`valuemark.invalid`). All 66 formats of the map parse; `FuzzParse` ran five minutes clean. `docs/citation-formats.md` is the syntax's domain doc; tests read doc tables through the new `core/internal/doctable`. No version bump.
