**S15-27 — The provenance table folds a page at a time** ([#1006](https://github.com/Jake-Robins-Studios/provenencia/pull/1006)). The provenance sheet's record table draws its first 50 records and ends with the kit's "Show 50 more" row; each press reveals the next 50 records. **S15-14 — The citation format engine** ([#868](https://github.com/Jake-Robins-Studios/provenencia/pull/868)). `core/citationformat` is the one engine for a Source type's citation formats, in Go with no database and no caller yet: `Parse` reads the syntax (levels named, groups, italics, chains, escapes) into a tree or into every diagnostic with its byte span; `Render` fills it through a resolver into italic and plain runs, with unknown and supplied values printed as citation style marks them, and stops at 64 KiB of text; `Requirements` and `Missing` say which fields a type's formats need or use and which needed ones have no value; `RewriteFields` moves a format's field references between keys and ids without touching any other byte.
